## 1. 배경 및 목적

### 문제 정의
MZ세대 버터떡 애호가들이 맛집 정보를 여러 곳에서 흩어져 찾아야 하는 불편함이 있음.

### 비즈니스 목표
버터떡 맛집 정보를 한 곳에서 탐색하고 저장할 수 있는 웹 서비스 MVP를 출시한다.

---

## 2. 목표 (Goals & Non-Goals)

### Goals (이번 범위에 포함)
- 버터떡 맛집을 지도로 시각화하여 탐색
- 운영진 제공 + 유저 직접 등록으로 맛집 데이터 수집
- 즐겨찾기/저장 기능으로 나만의 맛집 리스트 관리
- 웹 MVP 빠른 출시 및 검증

### Non-Goals (이번 범위에서 제외)
- 모바일 앱 (iOS / Android)
- 커뮤니티 / 피드 기능
- 레시피 아카이브

## 4. 기능 요구사항

### 4-1. 핵심 기능

| 번호 | 기능 | 설명 | 우선순위 |
|------|------|------|---------|
| F-01 | 맛집 지도 시각화 | 버터떡 맛집을 지도 위 핀으로 표시, 클릭 시 상세 정보 확인 | P0 |
| F-02 | 맛집 목록 | 지도 외 리스트 형태로도 맛집 탐색 가능 | P0 |
| F-03 | 맛집 등록 | 운영진 직접 등록 + 유저 제보/등록 | P0 |
| F-04 | 즐겨찾기 / 저장 | 마음에 드는 맛집을 저장해 나만의 리스트 관리 | P0 |

### 4-2. 상세 플로우

**플로우 1: 맛집 탐색**
1. 웹 접속 → 지도 화면 진입
2. 지도에서 핀 확인 (위치 기반)
3. 핀 클릭 → 맛집 상세 정보 (이름, 주소, 사진, 설명) 확인
4. 즐겨찾기 버튼 클릭 → 저장

**플로우 2: 맛집 등록 (유저)**
1. 등록 버튼 클릭
2. 가게명, 주소, 사진, 설명 입력
3. 제출 → 운영진 검토 후 지도에 반영
