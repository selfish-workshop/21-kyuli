## S-01. 메인 지도 화면

**목적**: 사용자가 버터떡 맛집의 위치를 지도 위에서 한눈에 파악한다.

### UI 요소

| 요소 | 타입 | 설명 |
|------|------|------|
| 지도 영역 | Map | 전체 화면 차지. 맛집 위치에 핀(마커) 표시 |
| 맛집 핀 | Marker | 각 맛집 위치에 표시. 클릭 시 S-02 상세 진입 |
| 검색 바 | Input | 상단 고정. 가게명 또는 지역으로 검색 |
| 헤더 로고 | Image/Text | 좌측 상단. 서비스명 "버터떡 지도" |
| 현재 위치 버튼 | Button | 우측 하단. 내 위치로 지도 이동 |
| 맛집 등록 버튼 | Button (FAB) | 우측 하단. 유저 맛집 제보 진입 |

### 상태

| 상태 | 설명 |
|------|------|
| 기본 | 전국 맛집 핀 전체 표시 |
| 검색 결과 | 검색어에 해당하는 핀만 필터링 표시 |
| 핀 없음 | 검색 결과 없을 시 "등록된 맛집이 없어요" 메시지 |

### 비고
- 지도 API 미정 (카카오맵 / 네이버지도 / Google Maps 중 선택 필요)
- 모바일 웹 대응 시 핀 크기 및 터치 영역 재정의 필요

## S-02. 맛집 상세

**목적**: 선택한 맛집의 상세 정보를 확인하고 즐겨찾기에 저장한다.

### 진입 경로
- S-01 지도 화면에서 핀 클릭 → 하단 시트(Bottom Sheet) 또는 모달로 표시

### UI 요소

| 요소 | 타입 | 설명 |
|------|------|------|
| 가게 사진 | Image | 상단 대표 이미지 (없을 경우 기본 이미지 표시) |
| 가게명 | Text (H1) | 맛집 이름 |
| 주소 | Text | 도로명 주소 |
| 영업시간 | Text | 운영 시간 (미등록 시 "정보 없음") |
| 설명 | Text | 맛집 소개 한 줄 또는 메모 |
| 즐겨찾기 버튼 | Icon Button (하트) | 클릭 시 즐겨찾기 추가/해제. 저장 상태는 색상으로 구분 |
| 지도앱 연결 버튼 | Button | 카카오맵 / 네이버지도로 길찾기 연결 |
| 닫기 버튼 | Button | 상세 닫고 S-01로 복귀 |

### 상태

| 상태 | 설명 |
|------|------|
| 기본 | 맛집 정보 표시, 즐겨찾기 미저장 상태 |
| 즐겨찾기 저장됨 | 하트 아이콘 활성화 색상으로 변경 |
| 이미지 없음 | 기본 플레이스홀더 이미지 표시 |

### 비고
- 즐겨찾기 로그인 필요 여부 미결정 (로컬 저장 vs 계정 기반 — PRD 열린 질문 참고)
- Bottom Sheet vs 별도 페이지 이동 방식은 디자인 단계에서 결정
